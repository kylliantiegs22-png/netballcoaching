# Wests Netball Coach

An iPhone app for netball coaches at Western Districts Netball Association.

This repo is a starting point only, and no app code exists yet:
- `docs/goal-prompt.md` is the build brief for Claude Code's `/goal` command.
- `docs/design-brief.md` covers users, design principles, the netball model, default stats and Wests branding.
- `data/rep-calendar-2027.json` holds the 2027 WDNA rep calendar (JSA, SSA and GBNL, 123 events), taken from the official PDF.
